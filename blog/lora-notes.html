LoRA Without Regret — Reading Notes

Aug 8, 2026

hova88

Today’s leading language models contain upwards of a trillion parameters, pretrained on tens of trillions of tokens. Base model performance keeps improving with scale — but post-training involves smaller datasets and narrower domains. It seems wasteful to use a terabit of weights to represent updates from a gigabit of training data.

The leading parameter-efficient method is low-rank adaptation (LoRA). LoRA replaces each weight matrix $W$ with a modified version $W' = W + \gamma BA$, where $B$ and $A$ are low-rank matrices with far fewer parameters than $W$, and $\gamma$ is a scaling factor.

What matters for LoRA

The key question is not whether LoRA has enough capacity, but whether it matches full fine-tuning in sample efficiency and ultimate performance. When a few details are tuned correctly, LoRA can learn with the same sample efficiency as FullFT.

  • For small-to-medium instruction and reasoning datasets, LoRA matches full fine-tuning.
  • When datasets exceed LoRA capacity, efficiency degrades — not a hard floor, but worse scaling.
  • LoRA is less tolerant of large batch sizes than FullFT in some settings.
  • Applying LoRA to MLP (and MoE) layers matters more than attention-only LoRA.
  • For RL, even small ranks perform equivalently to FullFT.

Learning rate and rank

A useful rule of thumb from the literature: the optimal learning rate for FullFT tends to be about 10× lower than for high-rank LoRA. The $1/r$ prefactor in standard LoRA implementations makes the optimal LR approximately rank-independent across a wide range.

The outcome is a “low-regret regime” where LoRA performs similarly to FullFT — covering most post-training scenarios in practice.

Minimal PyTorch snippet

class LoRALinear(nn.Module):
    def __init__(self, base: nn.Linear, rank: int, alpha: float):
        super().__init__()
        self.base = base
        self.base.weight.requires_grad_(False)
        self.A = nn.Linear(base.in_features, rank, bias=False)
        self.B = nn.Linear(rank, base.out_features, bias=False)
        self.scaling = alpha / rank

    def forward(self, x):
        return self.base(x) + self.B(self.A(x)) * self.scaling

Reference: LoRA Without Regret (Thinking Machines Lab, 2025).
